# ブラウザ版ねいねいチャットbot

`index.html`をブラウザで開くと、LINE風のチャット画面で「ねいねい」botを試せます。

画面右側で次を変更できます。

- 名前
- 相手の名前（`〇〇`に入る名前）
- 肩書き
- 性格
- 口調
- 決め台詞
- 会話スタイル
- 返答の長さ
- 絵文字の有無
- OpenAI APIキー
- モデル
- 最新情報の検索

性格、肩書き、決め台詞に`〇〇`と書くと、画面で入力した相手の名前に置き換わります。

## 会話の仕組み

ブラウザ版はOpenAI APIへ接続して、ねいねいのキャラクター設定と直近20件程度の会話履歴を毎回モデルへ渡します。

キーワード判定で返答を分岐せず、ユーザーが前の質問に答えた場合は、その回答を前提に会話を続けるようにしています。

APIキーが未設定、またはAPI接続に失敗した場合だけ、短い案内文を表示します。

## 共有するときの注意

OpenAI APIキーは各ブラウザの`localStorage`に保存されます。GitHub PagesなどでURLを共有した場合、相手の画面にはあなたのAPIキーは共有されません。

他の人にもそのまま使ってもらうには、相手に自分のAPIキーを入力してもらうか、LINE移行時にサーバー側でAPIキーを管理する構成にしてください。

## ねいねい設定

初期設定は「ねいねい」にしています。ブラウザに以前の設定が残っている場合は、画面右側の「ねいねい設定に戻す」を押すと、ねいねいの名前・一人称・口調・決め台詞に戻ります。

## LINEへの移行

このデモのキャラクター設定、会話履歴、OpenAI API呼び出しは`script.js`にあります。LINE版に移すときは、`character`設定と`createLlmReply()`相当の処理をサーバー側の共通会話エンジンへ入れて、LINE Webhookから呼び出します。
